# 杀戮尖塔2：分道争锋

独立选路、独立战斗、遗物献祭的多人竞速 MOD。共享一张地图，各自推进；固定5幕，率先击败第五幕最终Boss的玩家获胜。

**已发布版本：0.4.1 开发预览。** 基于 Windows 版游戏 **v0.111.0**、**BaseLib 3.4.7** 验证。已完成本机原生战斗、图形和双进程网络测试，仍需 Steam 多机、三至四人和完整竞赛验收。详细证据见 [验证记录](docs/VERIFICATION.md)。

本地源码正在开发0.5.0，尚未上传；新增道具、保存恢复和改名进度见 [开发验收记录](docs/NEXT-EFFECTS.md)。以下安装包说明对应已发布的0.4.1。

0.4.1 包含第五幕高塔之心、持续心跳与演出、复制对手牌组、本地双窗口测试和多项修复；逆境生财改为跨幕保留，以战养战改为最多三层开战属性。详见 [更新说明](docs/releases/0.4.1.md)。

## 安装与更新

1. 所有参与者使用相同游戏版本，安装并启用 **BaseLib 3.4.7 或更新版本**。目前只验证了 3.4.7，更新版本仍需兼容核验。本包不附带 BaseLib 或游戏程序集。
2. 从 Releases 下载 `FendaoZhengfeng-0.4.1-preview.zip`，不要把自动生成的 `Source code` 源码压缩包当作安装包。
3. 退出游戏，将 ZIP 中的 `FendaoZhengfeng` 文件夹放入游戏的 `mods` 目录。可在 Steam → 游戏 → 管理 → 浏览本地文件找到游戏目录。

```text
Slay the Spire 2/
└─ mods/
   └─ FendaoZhengfeng/
      ├─ FendaoZhengfeng.dll
      └─ FendaoZhengfeng.json
```

4. 启动游戏，确认 BaseLib 与分道争锋均已启用；在主菜单“模组配置”左侧选择与 BaseLib 同级的 **分道争锋**。
5. 房主开启模式、勾选允许的效果，再通过原版多人房间开局。房主和所有客户端均须安装、启用相同版本的本模组。

更新时退出游戏，覆盖上述两份文件，所有人一起更新并新开比赛。不要保留同 ID 的多份安装。发行页同时提供 `SHA256SUMS.txt`，可以用 `Get-FileHash <安装包路径> -Algorithm SHA256` 核对下载文件。

## 五幕竞速

前三幕保留基础结构；第四、第五幕各有两场连续Boss，精英配额分别增加1、2个。每名玩家仍使用相同种子生成的共享地图布局、节点类型和Boss安排，各自独立战斗。两个Boss分别提供遗物领取/献祭，首杀奖励仅在本幕最后一个Boss结算；第五幕最后一个Boss结束才锁定名次。

第四、第五幕使用原生第二、第三幕的场景与遭遇池，分别增加20%、40%的怪物生命、伤害、格挡；与R键每次重开的20个百分点相加。当前没有新增敌人美术或无尽模式。

普通怪不额外掉落模式效果。普通档主要从精英献祭获得；精英献祭只抽普通/精英档，Boss献祭抽精英/Boss档。档位和稀有度分别展示，Boss档契约也不能从精英献祭取得、不能在营地或商店净化。

新增16项效果，共50项可配置。远征悬赏仅计获得后的精英胜利：当前第1/2幕每轮需3次，第3/4幕需2次，第5幕需1次；完成后继续下一轮，重复取得增加1进度。额外遗物仍可献祭。全部效果、强化和渠道见[效果一览](docs/EFFECTS.md)。

## 玩法

- 每人独立选择相邻节点、进行单人血量的战斗；进入同一节点也不会合并战斗，不等待其他玩家过幕。
- 精英和 Boss 的遗物奖励可领取，也可放弃**当前这份遗物奖励**，从混合池三选一：向对手施加诅咒、取得自身双刃契约、取得增益。不移除已有遗物，金币、卡牌和药水奖励保留。此游戏版本的原生 Boss 不掉遗物，因此模式额外补一份领取/献祭遗物。
- 诅咒允许叠加，从目标下一场战斗开始生效并持续，直到依法净化。营地只净化普通档；商店可净化普通、精英档，按档位、稀有度和层数收费；商店与营地不能净化 Boss 档。
- 每人开局额外获得原版蜥蜴尾巴，保留正常开局遗物选择。其他原版保命来源照常获得和生效，因此不是整局最多只能保命一次。
- 每幕最终 Boss 首杀可选增益或诅咒护盾；非首杀可选净化或护盾。它们独立于遗物献祭。
- 多数增益可重复取得并强化，但候选权重降低；小而轻、强买强卖持有后退出候选池，R键每次取得增加一次使用机会；已有双刃契约不重复持有。具体效果、负担补偿与价格见 [效果说明](docs/EFFECTS.md)。

**替死鬼的边界：** 抵挡一次符合条件的战斗致命伤害并留下 1 点生命。直接处决、强制死亡、主动支付生命和事件直接失去生命不受保护。“灾厄、吞噬”是机制举例，不是仅排除两个技能的名称名单。原版其他保命来源仍按自身规则生效；第三方模组若把处决实现为普通伤害，需要另行适配。

## 配置与队友信息

模组配置仅有模式开关、50 项效果勾选和调试开关。**本局规则以房主为准**，客户端本地勾选不会覆盖房主，也不会被永久改写。设置变更在下次开局采用。禁用效果不会进入候选；没有合法候选时保留遗物。

队友头像、当前/最大生命、幕层与状态默认显示。点击队友可打开原生牌组、遗物、药水详情；已打开详情是当时的快照，重新打开读取更新。效果图标在遗物区下方常驻，悬停查看说明。

卡牌有耐久时，右上角用原版费用样式的边框显示剩余次数；左上角保留原版能量。战斗内需要展示的模式效果使用角色或敌人下方的原生状态图标，悬停可查当前数值。它们只负责展示，不额外触发原版状态获得逻辑。

奖励、净化与选效果使用原版奖励按钮样式，图标悬停显示完整效果。多选一入口使用专用图标，点击进入选择。主动增益可点击常驻图标操作。

| 新效果 | 行为 |
| --- | --- |
| 技艺封存 | 下场开战移出全部技能牌；每次胜利可从移出的技能中选一张取回，取完即止 |
| 小而轻 | 非战斗时选牌删除，每张扣3最大生命；持有后不再抽到 |
| 和你的升级说再见吧 | 包括施加者在内的所有玩家从各自下场起不能再升级，既有升级保留 |
| 强买强卖 | 100金起购买对手的牌，每成功购买加50金；钱给原主人，双方各自在下场开战交接；持有后不再抽到 |
| R键 | 每次获得增加一次主动重开机会；保留物品与状态回到第一幕，每次重开使怪物生命、伤害、格挡额外增加20个百分点，此后始终获得首杀Boss奖励资格 |

地图使用角色颜色的原版手绘通关标记，不画路线：真正击杀后才标记；多人通过同一节点并排显示，同角色使用不同色调。当前只展示当前幕地图，尚无历史幕地图查看器，也没有远程战斗画面观战。

## 一个人本地测试

在主菜单“模组配置 → 分道争锋”开启调试模式，顶栏会出现“分道争锋”。点击后选择“本地模拟测试（无需好友）”。普通开局没有预装效果，可使用模拟攻击、增益、战斗、商店和营地工具检查场景。

0.4.1构建包含第五幕最终Boss“高塔之心”，包含独立战场、演出、死亡律动、承伤上限、强化循环及复制对手牌组技能；并保留金币结算、异种侵染与复活历史修复和双窗口调试快速结算：退出游戏后，双击源码目录的 `Start-LocalMultiplayer.cmd`，自动启动房主与客户端，分别操作地图和战斗。详见[双窗口测试说明](docs/MOCK_TESTING.md)。

关闭调试后顶栏入口隐藏，正常比赛操作和队友信息仍保留。真实网络比赛不提供模拟资源注入工具。完整步骤见 [模拟测试说明](docs/MOCK_TESTING.md)。

## 保存、恢复与已知限制

房主可在“比赛操作”发起保存并暂停。所有玩家完成房间结算并选择下个节点，进入共同保存屏障；全员就绪后保存共同检查点。

恢复时，所有人以原名单和角色重建房间，房主先在调试面板选择恢复共同检查点再开局。尚不支持任意时刻无损热重连、房主迁移，或有人已通关/淘汰后创建共同检查点。当前规则为 `1.0.0-design.5`，不同规则版本的检查点不能混用，预览版更新建议新开局。

主菜单“检测到模组加载错误”应查看日志或悬停原版提示，不能只凭画面判断是哪一个模组。**0.3.0 起已修复本模组旧式 BaseLib 依赖声明引发的清单迁移错误**，并增加原生加载错误检查。若更新后仍出现红字，请反馈游戏版本、模组列表、复现步骤和日志，分享前删除账号、路径等个人信息。

全部角色、第三方 MOD 组合、特殊敌人和手柄/不同分辨率尚未穷尽验证。本地模拟与 ENet 双进程通过不等于 Steam 多机、完整对局及平衡已验收。详见 [待决事项](docs/OPEN_QUESTIONS.md)。

## 从源码构建

需要 .NET 9 SDK、合法安装的游戏及 BaseLib。仓库不分发游戏、BaseLib 或反编译代码；源码通过引用本机程序集构建，不替换原版文件。

```powershell
git clone https://github.com/mrxiuer/sts2-fendao-zhengfeng.git
cd sts2-fendao-zhengfeng
./scripts/Build.ps1 -GameRoot "<游戏目录>" -BaseLibPath "<BaseLib.dll的完整路径>"
# 显式加 -Deploy 才复制到本模组专用目录
./scripts/Build.ps1 -GameRoot "<游戏目录>" -BaseLibPath "<BaseLib.dll的完整路径>" -Deploy
# 先退出游戏；验证需要上述部署已完成
./scripts/Verify-Native.ps1 -GameRoot "<游戏目录>" -Suite All
./scripts/Capture-Native.ps1 -GameRoot "<游戏目录>"
./scripts/Capture-Native.ps1 -GameRoot "<游戏目录>" -Advanced
./scripts/Capture-Native.ps1 -GameRoot "<游戏目录>" -Campaign
./scripts/Package.ps1  # 将已构建产物打包到 artifacts/releases，附 SHA256
```

构建同时运行独立规则检查，产物在 `artifacts/FendaoZhengfeng`。默认按 Steam 库相对位置查找 BaseLib；自定义安装用 `-BaseLibPath`。原生验证使用内存存档后端，测试日志在忽略的 `artifacts/verification`；不会运行正常玩家存档。不要在测试过程中启动另一份游戏。

运行包是单 DLL 加 JSON，含规则引擎及原创透明 PNG 图标，无需附属 Core DLL 或 PCK。工坊准备脚本仅生成本地工作目录，不执行发布；当前通过 GitHub 预览版分发，尚未发布 Steam 工坊。

### 高塔之心（本地0.4.0）

第五幕第二场Boss固定为高塔之心，第一场守门Boss与第四幕双Boss保留。第4敌方回合施放“众生回响”：复制一名对手的牌组快照为本地临时战斗牌，第5、6玩家回合使用，第7回合恢复自己的各牌堆；双方永久牌组不变。人工制品可以抵挡此负面效果。

调试模式下可点击顶部“分道争锋” → “测试：进入第五幕心脏战”，需要先结算当前战斗。两个本地窗口都可使用；正常对局不会自动跳幕。仅复制卡牌，不复制对方遗物、药水、角色状态或资源；跨角色牌按原生规则使用。详细机制、制作与验证见[心脏Boss说明](docs/HEART_BOSS.md)。当前GitHub预览版为0.4.1。

0.4.1调整：逆境生财每点已激活负担返还5金币，基础整局上限1000，跨幕保留且额度不重置；以战养战改为每次取得叠1层，开战每层获得1力量、1敏捷、1集中，最多3层，满层退出候选池。两端须同版本并重新开启测试局。
