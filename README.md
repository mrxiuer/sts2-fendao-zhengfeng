# 杀戮尖塔2：分道争锋

独立选路、独立战斗的《杀戮尖塔2》多人竞速 MOD。玩家通过献祭战后遗物，在干扰对手、自我契约和自身成长之间作出选择，争夺率先完成全部幕。

当前版本：**0.1.1 开发构建**。已进入代码实现阶段，完整设计范围保持不变。不是工坊正式发布版本，已验证与待验证内容分别记录在 [验证记录](docs/VERIFICATION.md)。

## 本地使用

1. 游戏及所有参与者使用相同版本 MOD。目前编译与原生接口核验基于本机 v0.111.0。
2. 最终本地产物放在 `D:\SteamLibrary\steamapps\common\Slay the Spire 2\mods\FendaoZhengfeng`，包含同名 DLL 和 JSON 清单。
3. 游戏启用 MOD 后，顶栏“分道争锋”面板提供下次多人开局的模式开关。普通单人开局保留原行为。
4. 全员启用模式后，通过原版多人房间选择角色并开始；MOD 在原联机连接上维护比赛，每个客户端运行个人单人战局。
5. 点击精英或 Boss 遗物奖励可选择领取或献祭。面板提供比赛进度、效果来源、Boss 额外奖励与商店净化；营地新增净化和耐久维护选项。

## 本地模拟测试

主菜单点击顶栏“分道争锋”→“本地模拟测试（无需好友）”。正常开局不预装效果，可通过测试工具模拟对手攻击、取得增益、进入战斗或商店/营地。效果图标在遗物区下方常驻，悬停显示原生说明。详见 [模拟测试说明](docs/MOCK_TESTING.md)。模拟局不替代 Steam 网络验证。

## 保存与恢复

房主可在面板发起“保存并暂停比赛”。各玩家完成当前房间结算，再选择下一个地图节点，进入共同保存屏障。全员就绪后保存同一比赛修订号和各自原生战局包，再由房主继续。

恢复时，全员使用原玩家名单和原角色重建多人房间，并勾选“恢复上次共同检查点”。尚不支持任意时刻断线的无损热重连、房主迁移，或有人已通关/淘汰后创建共同检查点。没有共同检查点时，不能把个人调试快照冒充安全恢复点。

## 构建与验证

需要 .NET 9 SDK 和本机游戏程序集；无需修改或复制原版 DLL。构建脚本优先使用项目私有 `.tools/dotnet`，否则使用系统 SDK。

```powershell
./scripts/Build.ps1
./scripts/Build.ps1 -Deploy
./scripts/Verify-Native.ps1 -Suite All
./scripts/Prepare-Workshop.ps1
```

`Build.ps1` 编译并运行规则检查，只在显式指定 `-Deploy` 时部署独立 MOD 产物。原生验证会启动隐藏的游戏进程，使用游戏内存存档后端；网络验证使用本机原生 ENet。运行前退出已有游戏进程。日志保存在忽略的 `artifacts/verification`。

## 目录与分发

仓库：`D:\Projects\sts2-fendao-zhengfeng`。源码、文档、研究和中间产物保留在仓库，游戏 mods 目录仅接收运行包。发行使用单 DLL 打包，避免原生加载器在初始化前扫描类型时无法解析附属程序集。

不替换游戏 EXE、原版 DLL、原版 PCK 或其他 MOD。通过原生加载器和加载期间运行时补丁扩展游戏。当前没有必需 BaseLib 依赖。

工坊准备脚本生成官方上传器格式的私有工作区，不上传；正式发布前仍需封面、署名/许可决定和 Steam 真实联机回归。必须保留首次发布生成的 mod_id.txt。
