# 0.5.1：中英文支持与兼容说明

2026-10-23 更新至原 [Steam工坊条目](https://steamcommunity.com/sharedfiles/filedetails/?id=3825045315)，保留好友可见性；[GitHub 0.5.1预览发行包](https://github.com/mrxiuer/sts2-fendao-zhengfeng/releases/tag/v0.5.1-preview)包含相同运行文件。旧0.5.0发行包保留。

- 游戏内跟随游戏语言，中文显示中文，英文及其他语言回退英文。包含65项效果名称与说明、配置、奖励选择、状态提示、保存恢复和调试操作。原生魅惑、时间线、心脏与傀儡文本也接入同一套翻译。
- 英文翻译保留数值占位符、百分比格式与原生 `{Amount}` 标记；语言不参与效果 ID、候选、规则计算或协议。共享新局的默认玩家名与语言无关，界面按本机语言显示角色名。
- 补充双语工坊标题/介绍及英文 README；工坊准备脚本会刷新本次发布文案，保留原工坊条目 ID 和好友可见性。
- 真实对照本机正式/测试分支程序集后，确认存在关键 API 不兼容。按用户要求以 public-beta 为准，保留最低游戏版本 0.111.0，不增加精确版本锁或最高版本限制。见 [核验记录](../API-COMPATIBILITY.md)。

验证：测试版引用构建0警告/0错误；95项规则与翻译检查通过，包含65项效果翻译覆盖、所有翻译占位符、中英文切换、未知文本回退、原生英文表初始化与数字格式。没有重跑历史全部原生专项、Steam多机对局或中英文界面视觉验收。

规则 `1.0.0-design.14` 和协议 `wire:4` 不变。切换语言后重新打开配置或选择界面；已打开的临时弹窗可能保留创建时语言。未直接覆盖本机游戏/模组安装；工坊订阅由Steam负责更新。
