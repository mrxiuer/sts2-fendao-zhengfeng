# 0.3.0 五幕竞速开发预览

比赛扩展为固定5幕：第四、第五幕各有两个不同Boss，精英配额分别增加1、2；各玩家继续共享相同地图布局并独立战斗。只有第五幕最终Boss胜利才完成比赛。

- 两场Boss分别提供遗物领取或献祭，本幕首杀/非首杀额外奖励只在最终Boss发放。
- 新增16项效果，共50项可配置；普通/精英/Boss档位重排，界面同时显示档位与稀有度。精英献祭不能抽到Boss档契约，普通怪不额外掉落效果。
- 普通档新增磨刃、轻步、整装、蓄势、静养、薄甲、露隙、磨损；精英档新增攻守轮转、重剑余势、困中求生、连打缴税、失序；Boss档新增孤勇王冠、破釜回响、远征悬赏。全部使用独立原创透明图标。
- 小而轻每次删除永久牌扣3最大生命，支付后至少留1；持有后不重复抽到。
- 远征悬赏只计获得后的个人精英胜利，当前第1/2幕每轮3次、第3/4幕2次、第5幕1次。完成后额外遗物可单独领取或献祭；重复获得增加1进度。
- 模拟面板新增下一幕与本幕两个Boss的测试入口。
- R键保留当前资源回第一幕，并重置原生遭遇游标，避免重开后双Boss跳过第一场。

第四、第五幕复用原生第二、第三幕场景与遭遇池，分别增加20%、40%的怪物生命、伤害和格挡，与R键每次20个百分点的强化相加。没有新增敌人美术或无尽模式。

## 安装

全员使用同版本游戏及模组；本次验证游戏v0.111.0、BaseLib3.4.7。退出游戏，下载FendaoZhengfeng-0.3.0-preview.zip，将其中FendaoZhengfeng目录覆盖到游戏mods目录。在与BaseLib同级的分道争锋配置中开启模式，规则以房主为准。

规则版本升级为1.0.0-design.5，旧规则检查点不能恢复，请新开比赛。安装包不包含游戏、BaseLib或反编译文件。SHA256SUMS.txt用于核对安装ZIP。

## 验证与范围

规则、原生战斗、五幕/双Boss、状态图标、原生存档和本机双进程ENet均有自动验证；两进程明确比较第四、第五幕地图连线、节点类型与Boss摘要。详细证据见docs/VERIFICATION.md。

Steam真实多机、三至四人、全幕正常打法及平衡仍需验收。无损热重连与房主迁移尚不支持。此版本为开发预览，尚未发布Steam工坊。
