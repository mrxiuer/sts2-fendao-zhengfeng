## 安装

全员使用相同游戏和模组版本；已验证游戏 v0.111.0 与 BaseLib 3.4.7。先安装、启用 BaseLib，再下载 **FendaoZhengfeng-0.2.0-preview.zip**，退出游戏后将其中 FendaoZhengfeng 文件夹放入游戏 mods 目录。不要使用 Source code 压缩包安装。

在“模组配置”中选择与 BaseLib 同级的“分道争锋”。模式与效果候选以房主为准；调试模式用于开启顶栏本地模拟入口。更新后建议新开比赛。

SHA256SUMS.txt 用于核对安装包。包内只有本模组 DLL/清单和说明文档，不包含游戏或 BaseLib 文件。
