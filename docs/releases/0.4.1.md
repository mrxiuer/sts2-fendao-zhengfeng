# 0.4.1 高塔之心与增益调整

## 主要更新

- 第五幕第二场Boss固定为高塔之心，保留守门Boss与第四幕双Boss。加入独立战场、持续双拍心跳、出场/攻击/过载/死亡演出。
- 心脏拥有死亡律动、每轮承伤上限与逐轮强化。“众生回响”在第4敌方回合复制另一名玩家的永久牌组快照，第5、6玩家回合使用本地临时副本，第7回合恢复自己的原牌堆；保留升级，不取走对方卡牌。人工制品可以抵挡。
- 心脏确认击杀后先锁定名次，再展示死亡演出与奖励；演出不影响其他玩家继续比赛。
- 逆境生财：营地/商店净化每点已激活诅咒负担获得5金币，基础整局上限1000，强化每次提高上限15。跨幕保留，领取额度不重置；Boss免费净化不发金币。
- 以战养战：每次取得叠1层，开战每层获得1力量、1敏捷、1集中，最多3层；满层退出候选池。移除原献祭回血，持续至自己下一次幕Boss击杀。

## 同步包含的修复与测试工具

- 修复有福同享首次进入节点的收入漏结算，悬停展示待到账金币。
- 过河拆桥改为对手精英档诅咒，下场激活；叠加变化不同原有卡牌，保留兼容稀有度与升级。
- 修复原生蜥蜴尾巴、瓶中精灵真实复活历史计数，供死不足惜追溯。
- 源码提供本地双窗口ENet启动器；房主和客户端调试面板均可快速击杀当前敌人并结算奖励。调试面板新增第五幕心脏战入口。
- 保留0.3.2的R键跨幕修复、耐久徽标及卡牌遮挡修复。README不加入模拟截图。

## 安装与升级

所有参与者退出游戏后更新到相同版本。将安装包内的 `FendaoZhengfeng` 文件夹放入游戏 `mods` 目录，启用本模组和BaseLib。依赖BaseLib 3.4.7，游戏验证版本v0.111.0；本包不包含游戏或BaseLib程序集。

规则版本为 `1.0.0-design.8`，请新开测试局，不混用旧规则检查点。设置仍以房主为准。双窗口启动器在源码中，普通联机只需安装运行包。
