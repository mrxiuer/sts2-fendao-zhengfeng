# 0.5.4 好友测试版

安装包通过[GitHub Release](https://github.com/mrxiuer/sts2-fendao-zhengfeng/releases/tag/v0.5.4-preview)分发，[Steam创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3825045315)继续沿用原条目并保持好友可见。源码以d727912为基线完成修复。

## 同步合作

房主在模组配置的“分道争锋”条目中开启“同步模式”，下一局生效。双方安装并启用同一版本。沿用原版多人选路、共同战斗、多人怪物数值及队友查看功能；精英和Boss遗物可以领取，或献祭换取增益和自身双刃契约。Boss额外奖励直接选增益。

同步模式不赠送开局蜥蜴尾巴。正常获取与350金币补充仍有效。不提供诅咒、逆境生财、以牙还牙及灾祸共鸣候选。异步模式继续独立选路与诅咒对抗。

## 修复

- 史莱姆布局重复刷新不再累计位移，按友方体型和状态栏重新排布，避免与傀儡、奥斯提重叠。
- 额外时间线的复制牌从原生自动出牌路径执行，恶魔之焰不再回手卡住；共享战斗从实际队友牌组建立快照。
- 核心领取登记提前到达时，客户端仍执行本端原生奖励发放，避免奖励组一直等待。
- 每位玩家独立持有模组运行状态；原生同步重建卡牌后保留交易编号和耐久，新牌编号避免重号。
- 主动道具走原版动作队列，同步选牌、付款和效果；购买卡牌在下场战斗交接。
- 团队R键保留各自资源共同重置；最终Boss为每人分别建立临时牌组，并还原各自原始牌堆。

## 验证

101项规则检查；原生史莱姆布局套件、双进程完整同步流程、额外时间线与异步Boss定向回归通过。完整流程覆盖精英与Boss奖励、刻意延迟的领取消息、删牌代价、购买付款和交接、350金币补尾巴、遁地回合就绪及双方Boss复制还原。记录见[验证说明](../VERIFICATION.md)。这不代表已穷举所有第三方模组和道具组合。

## 安装与更新

需要游戏v0.111.0 public-beta及BaseLib3.4.7。关闭游戏后，工坊用户等待Steam完成更新即可；若曾使用手动包，请移除mods中的FendaoZhengfeng副本，避免重复加载。手动安装用户将ZIP内的FendaoZhengfeng文件夹放入游戏mods目录，覆盖旧手动版本，并避免同时订阅同ID工坊模组。

所有参与者确认模组版本0.5.4并新开一局。规则为1.0.0-design.16，协议wire:6，不与0.5.3混用。本版本不提供退出后的继续比赛入口。
