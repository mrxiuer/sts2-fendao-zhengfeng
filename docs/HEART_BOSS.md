# 高塔之心：Boss制作与验收

状态：本地0.4.0已完成实现，规则、原生图形进程及双进程联机验证通过；随0.4.1预览版发布。最后画面复核与日志详见VERIFICATION.md。

## 已确定范围

- 第五幕保留两场Boss，第二场固定高塔之心；模式关闭不改变原版。
- 基础生命900，沿用幕数/R键统一强化；死亡律动固定1，第二次强化升到2。
- 每个玩家回合开始至下个玩家回合开始，合计最多损失最大生命25%；伤害与生命流失共享额度，允许原生灾厄/直接处决机制。
- 开场2层易伤、虚弱、脆弱，加入晕眩、黏液、伤口、灼伤、虚空各一张。
- 每个攻击周期包含2×12连击与40重击，顺序由共享种子确定。第4、7、10……敌方回合强化。
- 第一次强化+2力量和2人工制品；第二次+2力量并提高死亡律动；第三次+2力量并启用攻击未格挡伤害塞伤口（每次攻击行动最多3张）；第四次+12力量，第五次起每次+22力量。
- 第3玩家回合开始预警，第4敌方回合复制另一名仍在比赛玩家的牌组快照，生成本地临时战斗副本；该回合意图可悬停查看规则。不取走牌、不改对手、不需对手确认；人工制品可以抵挡。
- 暂存本地手牌/抽牌/弃牌/消耗堆原实例；第5、6玩家回合使用复制牌，第7玩家回合抽牌前恢复。新增状态牌保留；不得刷新永久耐久、改永久牌组、重复获得原有消耗牌或触发新增永久牌效果。
- 没有合格对手或对方牌组为空时跳过复制，正常强化。对方掉线不影响已经取得的复制数据。
- 使用已确认的心脏和战场美术，配合待机心跳、出场、攻击、过载、死亡崩解及胜利反馈。出场不锁操作；死亡演出使用原生3.2秒动画时长，击杀先锁定名次，不锁住其他玩家，不使跳过演出成为竞速优势。
- 心脏全程以双拍节律横向扩张、纵向收缩、回弹和轻微悬浮；过载后加快。跳动同步红金脉冲，重击使用多层扩散波，出场与死亡带短促闪光。死亡崩解使用不规则三角碎片，独立舞台保留演出。
- 内嵌资源随DLL分发，不改原版游戏、不依赖制作机器路径。
- 击杀经原生死亡判定确认后，房主先记录名次，再恢复牌堆与执行死亡演出；正常胜利钩子仍只记录一次胜场与奖励。演出独立于被清理的怪物节点。

## 复制边界

复制的是对方公开资料中的永久牌组内容及升级，不是对方此刻的手牌或抽牌顺序。临时牌由本地战斗重新创建并洗牌，自己的永久牌组不变。对方无需等待、不会失去卡牌；对方随后通关或掉线，不会撤走已经复制的牌。

不复制遗物、药水、力量、敏捷或角色资源。跨角色卡牌使用原生支持的规则；双进程验证中，铁甲战士使用故障机器人的电击正常生成充能球。第三方角色和卡牌的特殊资源仍取决于各自实现，未声称全量兼容。

第7回合恢复原有战斗卡牌实例与各堆次序，不把消耗牌放回抽牌堆；复制期间新增的状态/诅咒保留。提前净化众生回响也恢复原牌堆。原永久耐久不刷新，临时副本不写回永久牌组。

## 验收项目

- 原生实际战斗：注册、地图图标、场景、原生意图和状态悬停，无缺资源或本模组初始化错误。
- 实际七回合及后续强化：两种攻击、塞牌、力量、死亡律动和承伤上限，原生遗物及模式效果正确交互。
- 复制及恢复：不同卡牌内容、升级、各牌堆顺序/消耗状态、状态牌带回、永久牌组/耐久不变，不销毁原牌。
- 跨角色资源兼容；复制过程不得依赖对方操作或持有实际卡牌引用。
- 死亡、玩家淘汰、提前结束战斗均清理临时副本；结算冠军只记录一次，不被演出延迟或跳过影响。
- 真实双进程：同一心脏/共享种子/地图，对方快照复制、独立推进和正确名次。
- 第五幕守门Boss奖励、最终心脏奖励/首杀、R键重开、检查点恢复和普通模式回归。
- 实际图形进程截图与肉眼检查；不能用概念图代替实机证据。
- 补齐调试入口、测试说明、版本、资源提示词与验证记录；本机部署，除非用户另行要求不上传。

规则59项、Heart实机43项、HeartNetwork房主15/客户端16项通过。原牌堆恢复及死亡清理由同一个Cleanup入口处理，AfterCombatEnd钩子负责其他结束路径；未把代码覆盖写成所有第三方强制结束方式都已实测。完整旧功能回归及当前验证边界见VERIFICATION.md。
