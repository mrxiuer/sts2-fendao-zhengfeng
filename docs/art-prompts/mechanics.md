# 机制道具图标

本轮使用内置imagegen，每项独立生成透明PNG，原图内嵌到DLL；显示时缩放到128像素。生成结果已经复制到 `src/FendaoZhengfeng.Mod/Assets/icons/`，不依赖生成缓存路径。

统一方向：厚而不规则的近黑色轮廓，粗笔触手绘暗奇幻物件，旧金、骨白、橄榄绿和深青阴影；单个紧凑物件，透明背景；64像素下保持轮廓清楚，不包含文字、底板或边框。

| 文件 | 主体与含义 |
| --- | --- |
| tail_refill.png | 缝合的浅绿蜥蜴尾巴、骨针和琥珀色线，表示修补消耗后的尾巴 |
| chaos_core.png | 裂开的古铜球笼，包裹蓝色闪电、琥珀火与紫色暗影的分块晶核 |
| piercing_edge.png | 钢制短矛尖穿过破裂的黑铁盾牌碎片 |
| resonant_circuit.png | 一枚琥珀裂晶通过浅金弧线连接两枚深青小晶体 |
| second_forge.png | 厚重铁锤与红热刀刃碎片，配少量金色锻造火花 |

原生图形验证保存在本地 `artifacts/visual-mechanics/`，包含实际球槽、升级后的卡牌和状态栏。测试画面不放入README冒充正式对局展示。
