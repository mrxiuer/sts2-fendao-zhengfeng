# 本地模拟测试使用说明

0.4.1 开发构建自带交互式本地模拟模式，不需要同学在线，也不用建立 Steam 房间。它和联机模式使用同一份运行包、规则引擎及原生战斗接入；模拟对手没有独立游戏进程，因此不替代真实网络测试。

## 开始

1. 确认安装了 0.4.1，启动游戏并停留在主菜单。
2. 在“模组配置”左侧独立的“分道争锋”条目开启调试模式，然后点击顶栏的“分道争锋”，再点击“本地模拟测试（无需好友）”。
3. 选择角色。开局没有预装任何诅咒或契约，只有规则要求的蜥蜴尾巴。
4. 再次打开面板使用测试工具。进入战斗后可收起工具面板，效果图标仍在原版遗物区下方常驻显示。

模拟局不占用原版单人当前局，不生成正式比赛的共同检查点。退出后重新开启即为一份新的测试局。

## 工具

| 按钮 | 用途 |
| --- | --- |
| 模拟对手施加诅咒 | 选择具体诅咒，由模拟对手发动；可重复测试同名叠加与护盾 |
| 取得自身双刃契约 | 选择契约，仍遵守下场战斗激活；不会默认全部取得 |
| 取得自身增益 | 指定增益；可测试重复强化、历史成长和免死机制 |
| 进入普通 / 精英 / Boss 战斗 | 快速进入原生遭遇；已有战斗须先结算 |
| 进入商店 / 营地 | 快速检查净化渠道、费用和耐久维护 |
| 击杀当前敌人并结算奖励 | 跳过测试战斗，检查实际奖励与遗物献祭流程 |
| 模拟对手抢先击杀本幕 Boss | 验证非首杀奖励分支；每幕仍只能取得一次对应奖励 |
| 自己获得 500 金币 | 为商店测试补充原生金币 |
| 模拟对手获得 100 金币 | 测试有福同享的收入记录与节点结算 |

这些按钮只在模拟模式出现，真实联机没有测试注入入口。模拟奖励可指定效果，故不用于评估随机候选概率；真实精英和 Boss 的遗物奖励仍可正常点击，测试正式三选一流程。

## 建议先验证的场景

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 干净开局 | 不取得任何效果，进入战斗 | 打击、防御等原版费用不变 |
| 先苦后甜 | 在进入下一场前取得契约 | 每回合首张手动牌翻倍；打出后手牌恢复正常；第三张合法手动牌额外结算一次 |
| 契约待生效 | 战斗中取得先苦后甜 | 当前战斗费用不变，下场激活 |
| 诅咒时序 | 战斗中模拟施加力竭 | 图标显示待生效，当前力量不变；下场开战才减力量 |
| 同名叠加 | 施加两次力竭，进入下一场 | 合并显示层数，力量累计减少；一次净化移除整个同名效果 |
| 商店净化 | 获取普通或精英档诅咒，进入商店并补金币 | 面板显示正确价格，扣真实金币，整组移除；Boss 档不在可选列表 |
| 营地净化 | 进入营地 | 只允许普通档，占用一次营地行动；不能净化精英或 Boss 档 |
| 遗物献祭 | 进入精英或 Boss 并使用结算按钮，点击遗物奖励 | 可以领取或献祭后从混合池三选一；卡牌、金币等其他奖励保留 |
| 常驻图标 | 获取诅咒、契约和增益后关闭面板 | 遗物区下方仍显示图标；悬停可见原生样式说明，待生效及叠加数量可辨认 |

X 费仍沿用原生消耗全部能量，费用翻倍对其不生效。自动出牌不计入手动出牌张数。模拟模式是检查具体场景的工具，不表示所有角色、特殊敌人与 MOD 组合都已经覆盖。

## 自动验证

仓库中的 `scripts/Verify-Native.ps1 -Suite All` 依次运行原生游戏回归、双进程 ENet 与重启恢复。`scripts/Capture-Native.ps1` 使用真实图形渲染保存测试场景截图。自动验证使用内存存档；运行前退出已有游戏，避免同时占用运行文件。

这些检查和手动模拟应在向好友发包前完成。Steam 真实多机、三至四人、完整通关及平衡仍须另行验证。

当前版本：涅奥开局保留原生三选遗物，蜥蜴尾巴额外赠送；Boss 战后有一份模式遗物可领取或献祭，献祭混合三选一保证至少一项 Boss 档诅咒。首杀额外奖励独立领取。

正式默认关闭调试，顶部文字入口隐藏。队友栏、比赛操作和效果图标始终可用；正式联机不暴露效果／金币注入。模拟局沿用本机效果勾选，禁用效果也不显示在模拟选择列表。

## 主动效果与状态检查

在模拟局注入盛放与凋零，打出一张手牌，查看右上角耐久数字递减；角色/敌人下方的模式状态悬停应显示当前值。打开营地或商店净化，检查每个图标的悬停说明和价格，Boss档不能从商店净化。

取得技艺封存后进入下一战，技能牌移出；胜利后从专用奖励图标中选回原技能。取得小而轻，在地图点击其图标选牌，确认最大生命只扣3。取得强买强卖，点击图标购买模拟对手卡牌；分别推进到下场检查交接。取得R键，在地图点击后确认保留资源、重回第一幕；怪物生命、伤害、格挡增加。小而轻、强买强卖持有后不会再次成为献祭或首杀候选。

`Verify-Native.ps1 -Suite All` 还包括关闭模式的原版联机回归及Advanced新增效果检查；`Capture-Native.ps1 -Advanced` 保存耐久、战斗状态、原生净化悬停和重开地图的真实渲染截图。模拟对手不替代真实好友连接验收。

## 五幕与新增效果

模拟面板新增“进入下一幕（最多第五幕）”和“进入本幕第一/第二个Boss”。先结算当前战斗再过幕。第四、第五幕地图应显示两个相连Boss；第一Boss不发幕首杀奖励，第二Boss才发，第五幕最终Boss才完成比赛。模式关闭的普通单人/多人不改幕数。

新增效果可逐项从模拟增益/契约/诅咒中取得。远征在第五幕只需打1个精英即可出现额外遗物；额外遗物可以单独领取或献祭。普通怪没有随机掉落效果。已升为Boss档的契约不再显示在商店净化列表。

自动验证新增 `Verify-Native.ps1 -Suite Campaign`，含原生5幕与双Boss、精英配额、固定种子地图、新效果与原生存档回归。All包含该套件。

## R键跨幕回归

先进入第四或第五幕，确认是双Boss地图；在非战斗时获得并使用R键，回到第一幕。随后通过原版战后入口进入第二幕，再用调试面板进入第三幕，确认不会出现 `NBossMapPoint` 已释放错误。再次从第五幕使用R键并跨幕，也应正常。自动Advanced套件覆盖这两轮重开与原版/调试跨幕路径。

## 两个可手动操作的窗口（本地0.3.3构建）

需要 Steam 保持登录一个有游戏许可的账号，无需第二个账号。先退出普通游戏，安装0.4.1或更新构建；启动器位于源码目录。开发机已部署，其他源码检出先运行 `./scripts/Build.ps1 -Deploy`。

双击仓库根目录 `Start-LocalMultiplayer.cmd`，或在 PowerShell 7 运行：

```powershell
Set-Location 'D:\Projects\sts2-fendao-zhengfeng'
./scripts/Start-LocalMultiplayer.ps1
# 可指定同一局种子、本机端口及游戏目录
./scripts/Start-LocalMultiplayer.ps1 -Seed 'TEST001' -Port 39182
```

脚本启动两个960×600窗口并自动通过本机ENet连接。标题分别是“房主/1号”“客户端/2号”，目前两边都是铁甲战士，可分别选择开局遗物、地图节点，独立打牌和领取奖励。使用Alt+Tab切换，或Win+左右方向键并排。无需在Steam中邀请自己；请勿再点击“本地模拟测试”替换本次联网比赛。

房主的效果勾选作为本局配置，测试局强制开启模式与调试显示；不自动发金币、效果或代打。精英/Boss遗物献祭、对手信息和通关颜色标记按实际联机逻辑工作。两个窗口是真实独立进程，此入口不覆盖Steam好友邀请和Steam网络链路。

关闭任意一个窗口会结束这次测试，脚本只清理它自己启动的进程。测试局使用全解锁的内存测试存档，退出后不续局；本次日志和手动共同检查点写入 `artifacts/interactive/<时间>/`，不覆盖正常玩家存档、解锁进度或其他测试记录。两个窗口默认静音以免叠音。

自动启动检查使用 `./scripts/Start-LocalMultiplayer.ps1 -Smoke`；它会在双边开局和队友资料同步后退出。原有 `./scripts/Verify-Native.ps1 -Suite Network` 仍是自动、无窗口的完整网络回归，两者用途不同。

## 历史追溯回归（本地0.3.4）

新开测试局，在取得死不足惜前触发一次原版蜥蜴尾巴，再取得增益：提示应显示累计真实复活1次，最大生命获得10%加成但当前生命不额外恢复；随后瓶中精灵再触发，应累计2次。普通治疗和替死鬼挡伤不增加此计数。愈战愈勇在取得前的胜利同样计入，实际伤害/格挡应获得对应加成。

运行 `./scripts/Verify-Native.ps1 -Suite Revival` 可自动检查真实复活、取得前后加成、实际伤害与格挡、普通治疗/替死鬼/处决边界和原生序列化。旧版已经漏记的复活不能可靠还原，请重新开局。替死鬼与远征悬赏仍只累计取得后的对应胜利。

## 双窗口快速结算（本地0.3.5）

启动两个窗口后，在任意一方进入战斗，点击顶部“分道争锋” → “测试：击杀当前敌人并结算奖励”。会关闭调试面板并击杀当前窗口的敌人，走正常死亡、胜利、卡牌/金币/遗物奖励、献祭和Boss奖励流程；另一窗口继续自己的战斗。召唤或分阶段敌人会继续处理后续敌人。

房主和客户端均可使用，只在房主开启调试模式时显示；普通联机也适用。没有战斗时点击会提示，不会发奖励；重复点击不会重复结算。共同暂停请求期间仍可完成当前战斗，到达保存屏障后不可使用。单人Mock仍保留原有入口，额外的模拟对手、跳幕、发放效果工具仍只限单人Mock。

## 有福同享与异种侵染（本地0.3.6）

有福同享不是即时金币复制：取得后，将鼠标移到效果图标上可查看最高对手收入和待结算金额；自己进入下一个节点时到账。取最高对手的累计正常收入的50%，基础上限30金，强化每次增加上限5金；复制收入、转账及模式发放金币不递归复制。修复新局首次记录节点之前的收入漏结算问题。

异种侵染改为精英档稀有诅咒，献祭后施加给对手，不再给施加者自身契约。从目标下一场战斗开始，新增永久卡牌时，随机变化1张已有且可变化的牌；叠加每层多变化1张，同次触发不重复选牌，保留兼容稀有度与升级，不变化本次新增牌。可在商店净化整个同名诅咒。请新开0.3.6测试局，两端均安装相同版本。

## 高塔之心（本地0.4.0）

更新后重新开局。双击 `Start-LocalMultiplayer.cmd` 启动两窗口，分别选择开局奖励。若已有战斗，先用“击杀当前敌人并结算奖励”；然后点击“分道争锋” → “测试：进入第五幕心脏战”。每个窗口独立跳到自己的第五幕最终战，不带动另一人。不要在同局切换回单人Mock。

正常进入第五幕也会在第二Boss节点遇到心脏。调试入口只负责跳转，不发放额外生命/金币/效果；验收脚本中的5000生命只是隔离测试夹具，正常玩法没有这项福利。

观察血条下方死亡律动、剩余承伤额度、力量与人工制品。第3玩家回合开始显示预警，第4回合意图可悬停查看众生回响；第5、6玩家回合使用对方牌组临时副本，角色下方显示来源与剩余回合，第7回合抽牌前恢复。复制期间受施加的状态牌应保留，己方消耗牌不应回到抽牌堆，永久牌组/升级/耐久不因替换刷新。人工制品可以抵挡复制；没有合格对手时跳过该技能。

出场演出不锁战斗操作；死亡演出使用原生3.2秒动画时长，避免奖励面板提前遮挡。跳过按钮只关闭视觉，名次在击杀确认时先锁定，再执行牌组收尾与奖励。

自动验证入口：`Verify-Native.ps1 -Suite Heart`（单进程真实战斗）、`-Suite HeartNetwork`（双进程跨角色复制与名次），均包含在All。`Capture-Native.ps1 -Heart -OutputDirectory <目录>` 运行实际图形进程并保存画面，不使用概念图替代截图。

## 0.4.1 两项效果调整

下文为已发布0.4.1的历史说明。本地未发布0.5.0的变更与验证状态以 [NEXT-EFFECTS.md](NEXT-EFFECTS.md) 为准；逆境生财已改为每场胜利结算1／3／5金币，上限800、每次强化+400，商店不再提供模式诅咒净化。

重新开同版本测试局，在调试面板取得“以战养战”最多三次。悬停显示当前层数，开战时每层获得1力量、1敏捷、1集中；每回合不会继续增加，仍于下一次幕Boss击杀时结束。满层后候选池不再提供它，强制第四次取得会拒绝。原献祭治疗已移除。

逆境生财为整局增益：营地或商店净化已激活诅咒时，每点负担获得5金币，基础累计上限1000（强化每次提高15）。跨幕不消失，累计领取不重置。Boss免费净化、未激活诅咒和双刃契约不发金币。可运行 `scripts/Verify-Native.ps1 -Suite Economy` 在隔离内存局验证实际属性与金币，不改正常存档。

## 本地0.5.0机制验证

`scripts/Verify-Native.ps1 -Suite Mechanics` 验证新增的混沌核心、破甲尖锋、共振回路、淬炼余火、续尾针线、恶咒回响、凌空之翼。当前包含63项原生机制检查；`scripts/Capture-Native.ps1 -Mechanics -OutputDirectory <绝对目录>` 同时运行真实图形进程并保存球槽、卡牌升级和战斗状态画面。

覆盖：非机器人角色的实际球槽与可见球体、基础和强化后的生成间隔、穿透的一次性伤害结算、低格挡边界、传导强化与溢出伤害、二次强化的伤害/格挡/治疗与升级禁令、卡牌复制、降级后存档及重新强化、已有强化牌随道具强化增长，350金币补尾巴后再次挡住致命伤害，以及恶咒回响的原生负面状态、人工制品、临时降力量的单次放大和准确恢复。

凌空之翼另有快速入口 `scripts/Verify-Native.ps1 -Suite Flight`：验证连击重选、群攻集中、随机攻击锁定、原生痛击的伤害和易伤目标一致、同血量顺序、击杀后续击、攻击与非攻击减伤边界、格挡消耗、强化上限和战斗状态栏。

测试使用内存进度，实际截图中的高生命值是测试夹具。新增原生字段后本地规则版本为 `1.0.0-design.10`；旧规则检查点不混读。该版本尚未上传发布。


真实双进程 `Network` 验证恶咒回响与凌空之翼只作用于持有者的独立战斗，`Resume` 验证持有状态跨进程重启恢复。`Network` 另会在隔离报告目录写入检查点文件并验证最新内容；`Recovery` 验证掉线保存和双方重启恢复。性能修改与实测范围见 [PERFORMANCE.md](PERFORMANCE.md)。
