# 药水与刷新多人压力验证

使用与金币/选牌专项相同的四个真实ENet进程、每人160张永久牌、12项效果、120条胜利历史和3000条历史命令。每人10场实际战斗，按药水领取、卡牌刷新、药水刷新、遗物刷新、混合效果候选刷新分别测两次；每类客机共六个样本。通过原生奖励行、卡牌下方原生替代选项和真实刷新按钮的信号执行，不用直接修改结果冒充点击。

额外药水通过原生CombatRoom.AddExtraReward生成，真实领取会进入药水栏。刷新必须完成权威次数提交、原生候选更新、应用标记和收据确认；不得领取原奖励。实际重复刷新被拒绝，关闭重开混合选项保持候选与次数。两个药水领取精确增加两瓶，永久牌组仍160张，完整历史及已领取集合落盘一致。

后台队友资料自动同步只在命令通道空闲、资料至少稳定50ms后发送；显式交易/进房资料提交保留原顺序，成功的本机显式profile会更新自动同步缓存。额外原生验证实际打开选牌界面，强制一次资料更新到期，证明人类读牌期间队友资料继续刷新；持有命令信号量时不插入后台任务，释放后自动恢复。该验证在计时样本之外执行，不通过关闭队友信息来提速。
