# 图标资源与画风

0.1.2 将 0.1.1 的线框图标替换为手绘风透明 PNG：12 项诅咒、7 项双刃契约、10 项增益，以及 1 个分道争锋模式图标。

共同方向是与原版遗物图标相容的奇幻物件：深棕厚轮廓、夸张体积、清楚的大色块、旧金属和布料质感。按效果语义设计物件，不使用字母、数字、霓虹线框或统一方形底板。图标不直接复制原版游戏资源。

模式图标以中央黑石尖塔、两条分叉道路及交叉短剑表达独立路线与竞争。它接入原生 ModifierModel.Icon，而非只出现在自定义效果栏，替换之前原生缺图显示的 NOPE。

## 文件和来源

- 运行资源：`src/FendaoZhengfeng.Mod/Assets/icons/{effect_id}.png` 与 `mode_icon.png`。
- 生成方式：内置 image_gen，三组代理分别处理诅咒、契约与增益；每项单独生成。
- 最终提示词：`docs/art-prompts/`。资源与规则 ID 对应，不依赖中文显示名称。
- 原图保留透明通道，原始 PNG 作为内嵌资源进入同一 DLL。运行时只缩小显示纹理，不改写原图。

本版继续使用遗物区下方的常驻图标布局，数量、待生效状态和原生悬浮说明保持原规则。原生模式图、营地入口与效果候选共用打包内资源，无需额外安装 PCK，不依赖开发机素材路径。

## 检查

检查 52 个文件与目录映射完整、PNG 能解码、透明背景有效；在原生游戏进程加载全部效果纹理，并核对原生模式图返回专用纹理。通过实机截图检查原生顶栏与常驻效果区；图片大图美术审阅不替代小尺寸实机验证。
