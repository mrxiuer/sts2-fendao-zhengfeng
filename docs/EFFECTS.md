# 效果目录

本目录共 29 项效果。稀有度为普通、罕见、稀有；净化档位为普通、精英、Boss，两者互不替代。表中数值是用户确认的设计基线，尚未经实测。名称沿用已确认版本；“命运骰子”“先苦后甜”“盛放与凋零”仍为工作名称，不擅自视为最终命名。

## 一、对手诅咒：12 项

以下均从目标下一场战斗开始持续生效，直到净化。敌方增益默认针对初始敌人，不自动传给后续召唤物。强化数记为 k。

| 名称 | 稀有度 | 档位 | 基础与强化 |
| --- | --- | --- | --- |
| 力竭 | 普通 | 普通 | 每场开战降低玩家 1+k 力量，本场持续 |
| 失衡 | 普通 | 普通 | 每场开战降低玩家 1+k 敏捷，本场持续 |
| 铁幕 | 普通 | 普通 | 敌人每回合获得 2+2k 格挡；明确在玩家回合开始、适用的正常格挡清理之后提供 |
| 怯战 | 普通 | 普通 | 开战获得持续 1+k 个玩家回合的虚弱，不增加减伤比例 |
| 命运骰子 | 普通 | 普通 | 每玩家回合公开抽取一个整数百分比，下限 max(80-5k,50)，上限 110；同回合角色直接攻击共用倍率 |
| 滞念 | 罕见 | 普通 | 首次正常起手后加入 2+k 张杂念：不能打出，回合结束自动消耗，无其他效果 |
| 助凶 | 罕见 | 精英 | 敌人开战获得 1+k 力量，本场持续 |
| 甲壳 | 罕见 | 精英 | 敌人每回合开始正常覆甲衰减后获得 3+k 覆甲；按回合触发，不按多段攻击触发 |
| 血肉滋长 | 稀有 | 精英 | 敌人开战最大与当前生命增加原基础生命的 10%(1+k)，相加不复利，向上取整 |
| 倒刺 | 稀有 | 精英 | 每张攻击牌首次对每个敌人造成攻击伤害后反伤 1+k；同敌人多段只触发一次，群攻可按敌人分别触发 |
| 硬壳 | 稀有 | Boss | 每场前 3 个玩家回合，敌人每回合生命损失不超过开战最大生命的 max(40%-5%k,20%)，向上取整；之后撤销本效果提供的限制 |

倒刺伤害可被格挡，不触发反伤连锁。命运骰子不改变灾厄、直接失去生命、反伤、持续伤害、独立召唤物和充能球；不能通过重连或查看卡牌重新抽取。硬壳额度每回合重置，不逐回合加总；与原有上限取更严格者，不撤销怪物原生能力。即死、变身与多血条的精确互动仍待专项定义。

## 二、自我双刃契约：7 项

从选择者下一场战斗激活，持续到净化；不攻击对手、不计负担补偿。普通档可营地或商店净化，精英档仅商店或 Boss 奖励净化。当前携带时不重复抽取同名契约。更早讨论的强化参数不代表允许重复持有，最终重复语义须参照待决事项。

| 名称 | 稀有度 | 档位 | 已确认基础规则 |
| --- | --- | --- | --- |
| 孤注一掷 | 罕见 | 普通 | 每场首回合 +1 临时能量，但首回合结束前无法通过任何来源新获得格挡，不移除已经存在的格挡 |
| 借来的明天 | 罕见 | 普通 | 首回合 +1 临时能量、额外抽 1；第二回合基础能量与正常抽牌各 -1，最低 0，不吞额外资源；第一回合结束战斗不跨战追债 |
| 贪婪口袋 | 罕见 | 普通 | 原始正常战斗金币 +25%，向下取整；首次正常起手 -1 张，最低 1；复制金币不再加成 |
| 先苦后甜 | 稀有 | 精英 | 每回合第一张手动牌最终能量费用翻倍；第三张手动牌若合法可重放，免费额外结算一次 |
| 过河拆桥 | 稀有 | 精英 | 每次永久牌组新增一张非状态、非诅咒牌，将原有一张合法牌变为其他角色同稀有度兼容牌，保留合法升级 |
| 预借时间 | 稀有 | 精英 | 每场每个玩家回合正常恢复能量后 +1 临时能量，同时给自身 +3 灾厄；灾厄本场累计，按原版玩家时机判定 |
| 盛放与凋零 | 稀有 | 精英 | 每次正常卡牌奖励多一次独立三选一；常规永久可打出牌获得 8 耐久，每次手动打出消耗 1，归零进入枯萎，后续表现为粘液 |

先苦后甜：0 费翻倍仍为 0；重放不计作手动出牌，不再次触发自身。X 费、不能重放的第三张和失去目标等尚需逐项定义，不能自行替换为第四张牌。

过河拆桥：变化不算新增，不递归触发；新加入的牌不参与本次原有牌抽取。临时战斗生成牌不触发，不可变化、绑定身份及任务牌排除；没有兼容牌则跳过，净化不回滚过去变化。基础牌使用基础档候选；兼容牌的具体清单待验证。

预借时间：灾厄不是普通扣血；界面显示灾厄与生命。替死鬼不保护灾厄死亡，其他原版保命来源只在其原有合法条件下生效。本效果不新增绕过机制杀的能力。

盛放与凋零：在本次卡牌完整结算后处理耐久归零；保留原卡身份、升级和耐久。临时生成、状态、诅咒牌及自动重放不扣耐久。粘液消耗不代表删除原卡，不触发有难同当。营地维护恢复全牌 8 耐久并解除枯萎；净化契约恢复原卡、移除耐久规则，不撤回额外获得的奖励。变化、复制、升级对原卡身份及耐久的继承细则尚待补齐。

### 经济与跨玩家事件

有福同享仅统计实际原生金币，不复制历史、其他跨玩家复制、退款或转账。贪婪口袋的额外金币不进入可复制基数，防止多效果相互放大。金币整数舍入顺序仍需明确。

逆境生财不处理未激活诅咒、契约自动结束、普通删牌或重复读档；尚未定义负担的双刃不计。以战养战的多人命中仍只治疗一次，即使全部目标有护盾，成功发动攻击仍可触发；献祭契约或成长不视为攻击。

有难同当不复制主动生成牌、耐久枯萎或转发牌；复制不再转发。每目标开战消费队列一次，牌为临时战斗牌。以牙还牙的反击塞牌不是新的献祭攻击，不反射回环、不产生负担，护盾挡住的攻击不触发。

汲取没有卡牌奖励时不能发动；不触发新增牌或过河拆桥。与盛放与凋零并存时最多献祭一个选牌机会，另一份仍可领取。能量记录在下一场开战消耗一次，原战斗内复活不重复发放。

### 历史成长与免死

愈战愈勇只记录个人独立战斗胜利；同一遭遇只计一次，逃离、失败、观战、召唤和恢复存档不增加。结算时入账，新系数从下一场使用。伤害不扩展至灾厄、反伤、持续伤害、独立召唤物或充能球。

死不足惜只计算实际发生的个人合法复活，不包括替死鬼、召唤物复生或队友复活。最大生命按不含本增益的当前最大生命基数乘 1+系数×复活次数，向下取整，不复利；新增最大生命不治疗。复活先按原机制完成，再更新成长，不重复治疗。

替死鬼从获取后零计数起步，不追溯历史。每五胜结算一次，满两层时新层作废，无隐藏库存。只抵挡本次伤害，多段后续仍可致死；可处理普通攻击、反伤和普通持续伤害，不处理灾厄、吞噬、直接处决、主动支付生命或事件直接失去生命。普通伤害致死时先消耗替死鬼，之后才尝试原版其他保命手段，同一次不重复消耗。

愈战愈勇与死不足惜的 MOD 百分比相加，再与正常战斗修正配合；命运骰子系数另乘，最终取整。此处只改变战斗格挡，不增加诅咒护盾次数、覆甲层数或替死鬼储存上限。
