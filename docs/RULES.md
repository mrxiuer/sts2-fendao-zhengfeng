# 玩法规则基线

状态：截至 2026-10-18，汇总本会话已确认规则。未确认事项列入 OPEN_QUESTIONS.md。后续平衡调整应修改文档并保留版本差异。

## 1. 正式术语

| 术语 | 定义 |
| --- | --- |
| 诅咒 | 对手通过献祭施加的持续干扰，不等同于牌组中的诅咒牌 |
| 双刃契约 | 玩家主动选择、施加给自身的持续正负混合效果 |
| 增益 | 有限时长、次数或持续本局的正面效果 |
| 净化档位 | 普通、精英、Boss；固定绑定效果，决定净化渠道 |
| 稀有度 | 普通、罕见、稀有；用于候选权重、负担和价格 |
| 诅咒护盾 | 抵挡下一次收到的诅咒攻击；可累计，与战斗格挡无关 |
| 战斗格挡 | 吸收战斗伤害的数值，不代表诅咒护盾或免死次数 |
| 强化数 k | 无后缀时为 0，名称后 +1 时为 1；同名诅咒累计次数为 k+1 |

## 2. 地图与个人进度

共享同幕地图结构、幕顺序、Boss 和难度，各自记录位置、路线和房间状态。玩家沿合法路径独立推进，不等待全员选路、结束战斗或过幕。同节点也分别创建个人遭遇，不相遇、不共享库存或奖励消耗。

采用单人怪物血量和相应单人规则；涉及多人目标、共享物品、投票和集体事件的内容需逐项适配，不能仅修改血量。同节点尽量提供相同基础遭遇与机会，角色牌池、抽牌和个人效果独立。具体随机种子契约尚待技术研究。

## 3. 战斗结束与献祭

精英和 Boss 战的遗物奖励可以领取或献祭。献祭只放弃这一份遗物奖励，金币、卡牌、药水等其余结算奖励不受影响，已拥有的遗物不受影响。战斗过程已经发生的回血、任务进展等不回收。

多份独立遗物奖励分别处理；一份多选一奖励算一份。已经领取的奖励不能回头献祭。每次献祭先选择干扰对手、自我契约或自身成长，再从相应池随机三选一。三条路线不能兼得。候选与代价应在提交前完整展示；候选是否允许在不同路线间反复预览尚待确认，且不得借此刷新随机结果。

干扰默认作用于所有仍在比赛中的其他玩家，允许跨幕；契约和成长只作用于选择者。攻击机会当场使用，不能囤积。献祭遗物与汲取卡牌奖励可分别发动。Boss 额外奖励不随遗物献祭丢失。

## 4. 诅咒、强化与时序

攻击在目标下一场战斗开战时激活，此后每场生效直到净化；不改变目标当前战斗。开战前后由统一事件边界区分，边界后的新攻击进入再下一场。

同名诅咒合并并强化：力竭、力竭+1、力竭+2 分别对应一次、两次、三次施加；数值按目录计算。一次净化移除所选同名效果及全部强化和相应负担。攻击来源与各次稀有度记录保留，界面可合并显示。

护盾在收到攻击时逐次抵挡，一层抵挡一份攻击，不清除已存在诅咒。群体攻击对各目标独立处理。淘汰者已施加的诅咒保留，淘汰者不能继续发动新攻击。跨幕不自动净化。

双刃契约从下场战斗开始激活并持续到净化，不发动对手攻击，不消耗自身诅咒护盾，不触发以牙还牙，不增加负担补偿。

## 5. 候选池和稀有度

| 场景 | 生成规则 |
| --- | --- |
| 精英干扰 | 每项以 75%/25% 选择普通档/精英档，再在相应池加权选取，三项同名去重 |
| Boss 干扰 | 一项 Boss 档、两项不同的精英档 |
| 精英契约 | 每项以 85%/15% 选择普通档/精英档，三项去重 |
| Boss 契约 | 三项中至少两项精英档 |
| 成长增益 | 限定渠道后，普通/罕见/稀有的相对权重为 100/50/20 |
| 首杀增益 | 三选一中保证至少一项罕见或稀有 |

保证位先生成，再排除已选名字生成其他项。先排除无收益或不合法项，候选不足则展示实际数量，不伪造重复项。剩余候选池为空、不能满足保证位时的交易回退方式待确认。

对已取得过的同名增益，候选权重乘 max(0.4^n, 0.1)，n 为本局历史取得次数。历史次数在效果到期后仍保留。这是相对权重，不是最终概率。干扰诅咒不因目标已有同名效果而降权，保留堆叠策略。

当前携带的同名双刃契约不再出现；净化后可再次出现，使用历史降权。已确定双刃效果的重复持有规则暂时优先于更早的强化草案，不自动重复强化；具体历史强化字段的归并见待决事项。

## 6. Boss 额外奖励与胜负

每幕首杀者选择增益或一层诅咒护盾；选择增益后再三选一。非首杀者选择净化一个完整诅咒或一层护盾，净化可处理任意档位，包括 Boss 档。奖励在个人完成战斗后结算，不等待全员。

每人开局获得原版蜥蜴尾巴，按其原版效果在当前战斗中保命，取消节点外复活重打。瓶中精灵等其他原版保命来源可正常取得并生效，不另设全局一次上限。复活不返还已消耗资源，不清除长期诅咒。

没有合法保命手段而死亡则淘汰，可观战。只剩一人仍须完成全部幕；全员淘汰则无人获胜。率先完成全部通关条件者锁定冠军，其他玩家可继续完成个人比赛争夺后续名次；不以动画播放结束或点击奖励作为完成时刻。近同时通关的裁定标准仍待确认。

## 7. 负担补偿

每次来自对手、成功施加且已激活的普通/罕见/稀有诅咒，分别贡献 1/2/4 点负担。强化仍累计每次攻击。护盾抵挡、尚未激活、自选契约、反击塞牌都不计；Boss 档不再另乘档位系数。

设负担为 B：稀有卡牌权重倍率为 1+2B/(B+8)，稀有遗物权重倍率为 1+1.5B/(B+8)。提高稀有权重后重新归一化，不增加奖励数量，不改写固定奖励和特殊遗物池。多选一牌组的联合概率与单项稀有率不同。

战斗开战激活诅咒后记录负担快照，用于该战斗随机奖励；途中收到的攻击不影响本场。非战斗奖励记录进入节点时的已激活负担。净化只影响之后的奖励。菜单重开、读档和重连不得重新抽取。

## 8. 净化和维护

营地以一次行动净化一个普通档诅咒或契约，包括全部强化；不能净化精英档或 Boss 档。

商店每个节点最多购买一次专用净化，与原版删牌独立。普通档基础 60 金，精英档基础 120 金；再乘稀有度倍率 1/1.25/1.5，及强化倍率 1+0.15k，最终向上取整至 5 金倍数。Boss 档无商店净化价格。

示例：力竭 60 金，力竭+2 为 80 金；甲壳 150 金，甲壳+2 为 195 金；血肉滋长 180 金。

恢复耐久是盛放与凋零的专用营地维护行动，并不移除契约，因此不绕过精英档净化限制。商店或 Boss 净化契约后恢复原卡并撤销耐久规则。

## 9. 信息公开

公开个人幕、楼层、生命、房间类型、诅咒、护盾与攻击来源；牌组和遗物不默认向对手公开。身份、进度与交易记录由比赛统一管理。额外调试信息不得泄露对手隐藏内容。
